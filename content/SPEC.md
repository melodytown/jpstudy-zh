# 人工原创内容

流水线只读不改的两份人工内容。除 `raw/` 的上游数据之外，这里是唯一由人写的地方。

## `confusables.tsv`

首行 `w	ja	zh`：词形、它的日语义、中文母语者容易误以为的中文义。例如 `手紙／信件／手纸`。

- 现有 102 条，覆盖牌组里会命中的词。
- `04-difficulty` 命中一次就给难度 +1.0，并在单元页给该词挂"⚠ 同形异义"标记、展开显示两边语义。
- 收录标准是"中文直觉会带偏理解"，不是"翻译不同"：`勉強／学习／勉强（不情愿地做）` 算，纯粹意译差异不算。

## `grammar-zh.json`

按语法点 id 给 `{ note, counter[] }`：中文讲解加反例/陷阱。接续（`formation`）与例句仍取自 OpenJLPT，这里只补中文。

- 键就是 OpenJLPT 的语法点 id，必须一一对上，否则单元页静默不显示中文。
- 条目形状固定为 `note`（中文讲解，一两句说清语义与使用条件）＋ `counter`（反例或陷阱，形如 `× 错例 → ○ 正例（原因）`）。只写中文，接续与例句仍取自 OpenJLPT。
- 覆盖完整性看 `08-site` 输出的 `grammarWithZh` 计数：它应当等于语法点总数（当前 526/526）。缺口不是 feature，而是本该补上的内容。
- 写的时候要人工审两栏："接续"是否说清、反例是否真的会犯——这两栏最容易写空。

新增/修改语法点解释后重跑 `npm run data:site` 即生效，不需要改站点代码。
