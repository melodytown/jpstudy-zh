# jpstudy · 中文母语者的日语学习站

## 目标

用一条可复现的数据流水线，把公开的日语词表、例句与音频整理成一套 N5→N1 的自学课程，再以纯静态站点（可打包成单文件桌面程序）交付。学习者打开就从"今天这一课"开始：背词、读句、按 FSRS 复习。

## 问题与受众

受众是作者本人——中文母语、要在 JLPT 全级别范围内系统扩词的学习者。

真正的难点不是缺词表，而是：

- **没有顺序。** 现成牌组给的是词，不是"先学哪些"。排课、控负载、控制进度曲线都得自己做。
- **例句对初学者太早。** 普通语料里一句话常带三五个没学过的词，读者被迫查词，学习循环就断了。
- **中文母语者有独有的偏差。** 同形异义词（手紙＝信件）、汉语词可猜义、纯假名词更难。通用难度分级不体现这一点。

## 能力

- **课程**：545 个单元，按 N5→N1 排列；每单元不超过 20 个新词、3 个语法点，加例句精读。
- **零生词精读**：每句例句里的每个词都在本课或更早已教过（规则 R1），读句不需要查词。
- **复习**：FSRS（ts-fsrs）四档评分，答错的卡当轮重来；卡片只在完成某课时入库。
- **单元页**：新词 → 精读（注音＋音频）→ 操练（活用／助词／中译日）→ 语法参考（折叠）。
- **五十音表**：清音、浊音、半浊音、拗音，平／片假名切换，点击朗读。
- **进度**：存浏览器 IndexedDB，首页可导出／导入 JSON。
- **桌面版**：单文件 exe（本地 HTTP 服务＋WebView2 窗口），双击即用。

## 非目标

- **无后端、无账号、无跨设备同步。** 进度只在本机浏览器里，搬运靠导出 JSON。
- **无构建工具、无前端框架。** 站点是手写 HTML/CSS/ESM，改完刷新即生效。
- 不做听说训练、能力考试报名、社区功能。

## 原则

- **数据流向单一**：上游 `raw/` → 中间产物 `data/` → 发布产物 `site/data/`。上游与中间产物都不入库，只提交流水线代码、原创内容与验收报告。
- **课程质量由机器判定，不由手感判定**：R1–R6 任何一条不过，整份课程就视为不合格（`curriculum-lint`）。
- **词的"教过位置"是唯一事实**：例句放在"句中最后一个词被教到的课"，所以除它之外不需要第二套"已知词"状态。
